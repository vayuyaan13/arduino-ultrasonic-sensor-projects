# Smart Dustbin Using Arduino and HC-SR04

A smart dustbin can use an HC-SR04 to detect a hand near the lid and a servo motor to open the lid automatically.

## Components

- Arduino Uno
- HC-SR04 ultrasonic sensor
- Servo motor
- Breadboard
- Jumper wires
- Suitable power source

## Basic workflow

1. Measure the distance in front of the lid.
2. Check whether a hand or object is within the chosen threshold.
3. Move the servo to the open position.
4. Wait for a short period.
5. Return the servo to the closed position.
